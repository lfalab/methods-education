QUESTION: Which type of variable best describes respondents’ gender coded as Male, Female, or Other?

A. Nominal variable
B. Ordinal variable
C. Interval variable
D. Ratio variable

ANSWER: A

---

QUESTION: Which type of variable best describes a five-point Likert scale measuring agreement from “Strongly disagree” to “Strongly agree”?

A. Nominal variable
B. Ordinal variable
C. Interval variable
D. Ratio variable

ANSWER: B

---

QUESTION: Which of the following is an example of a ratio variable?

A. Political ideology measured on a left–right scale
B. Country of residence
C. Number of children in a household
D. Level of trust in government (low, medium, high)

ANSWER: C

---

QUESTION: Which property distinguishes ratio variables from interval variables?

A. Ratio variables can be ranked
B. Ratio variables have categories without order
C. Ratio variables have a meaningful zero point
D. Ratio variables cannot be measured numerically

ANSWER: C
