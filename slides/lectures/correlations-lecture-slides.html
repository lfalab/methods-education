But first: why does any of this matter?

  • That’s a fair observation — and it’s worth addressing directly.

The building blocks aren’t obvious yet

  • Generating a histogram or tabulating a single variable can feel pointless.
  • But these are the building blocks of independent empirical analysis.
  • Right now you’re learning to use a tool. Later, you’ll decide what to do with it.

What you’re building toward

  • Problem Set 2 asks you to analyse a dataset of your choice, with variables of your choice.
  • You will need to identify the right tool for the right pair of variables — and execute it.
  • Everything you’ve done so far is preparation for that.

The do files are templates

  • The do files in our shared folder aren’t just course materials — they’re starting points for your own analysis.
  • You’ve set up an identical folder structure on your computer for exactly this reason.
  • Download a do file, update the working directory, and you have a working template.

What happens when you run a do file top to bottom

  • Stata executes every line in sequence.
  • Plots appear because the do file contains graph commands.
  • This isn’t magic — it’s a reproducible record of your analysis.
  • Today we’ll use a new do file as a template: bivariate-lecture.do
